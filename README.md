# sodobu-website

筑波大学書道部の活動・作品・ハワイ企画を紹介する静的ウェブサイトです。紫を主色、青を補助色に使用し、スマートフォン表示に対応しています。

## ページ

- `index.html`：トップ。部名・メイン写真・各ページの入口
- `about.html`：書道部の紹介・基本情報・見学案内
- `activity.html`：活動・お知らせ
- `works.html`：作品と拡大表示
- `support.html`：応援方法・お問い合わせ
- `hawaii.html`：ホノルルフェスティバル企画と支援方法
- `credits.html`：素材の出典
- `content.js`：写真、部の情報、支援先、連絡先の設定
- `styles.css`：共通デザイン
- `site.js`：写真の差し替え、作品の拡大表示、活動記録、連絡先の表示

## プレビュー

このフォルダーで `python -m http.server 8000` を実行し、`http://localhost:8000` を開きます。ビルドや外部パッケージは不要です。静的ホスティングでもそのまま配信できます。

## 写真の差し替え

1. 掲載許可を確認した写真を `assets/photos/` に配置します。
2. `content.js` の該当する `src` に、例えば `assets/photos/hero.jpg` と記入します。
3. `alt` に実際の写真内容を記載します。作品は `caption` に作品名・作者・制作年を設定できます。

写真の設定が空欄の場合は掲載予定の枠を残します。読み込みに失敗した場合は枠内に案内を表示します。作品は写真設定後に拡大表示が使えます。メイン写真は優先して読み込み、他の写真は表示位置に近づくと読み込みます。

人物などの位置を調整したい場合、写真の設定に `position: '50% 30%'` を追加できます。作品は全体を見せるため切り抜きません。

| 設定名 | 推奨写真 |
|---|---|
| hero | 制作・披露の横長写真。目安1800px以上 |
| about | 部員が一緒に活動する写真 |
| preparation | ハワイ企画の準備風景 |
| hawaii | 部の披露風景・代表作品 |
| work1 / work2 / work3 | 縦長・横長・その他の作品。文字と紙の端が見える写真 |

## 情報の更新

`info` に活動内容、日時・場所、見学案内を設定できます。`contactEmail`、`crowdfundingUrl`、`shopUrl` は確認済みの情報だけ設定してください。空欄では準備中として表示し、架空の申し込み先には案内しません。

200万円、クラファン100万円、作品販売20万円、資金目標日2026年12月31日は部の計画として掲載しています。その他の調達目標80万円は総目標との差額で、確保済みの助成金ではありません。資金計画の帯は調達方法の内訳で、実績を示す進捗バーではありません。出演確定の有無、参加する開催年・日程、募集期間、費用内訳、入金時期が確定したら `hawaii.html` の原稿も更新してください。

`contactEmail` を設定すると、メールリンクとアドレスのコピーボタンを表示します。コピーできない環境では手動でコピーする案内を表示します。フォームによる送信は行いません。`socials.instagram`、`socials.x` には部の確認済みのアカウントURLを設定できます。

## 活動記録を追加する

`content.js` の `updates` に、次の形式で記録を追加します。これは設定例です。実際の日付と原稿に置き換えてください。

```js
updates: [
  {
    date: 'YYYY-MM-DD',
    category: '活動報告',
    title: '記録のタイトル',
    body: '紹介文。改行も使用できます。',
    href: 'hawaii.html' // 任意。詳細ページへのリンク
  }
]
```

トップには新しい日付から3件、活動ページには全件表示します。正しい日付とタイトルのある記録だけを表示します。空欄では準備中の案内を残します。HTMLは入力せず、文章のみ設定してください。

## 作品を追加する

既存の `photos.work1`〜`work3` はそのまま使用できます。4点以上掲載する場合は、`works` に任意の数の作品を設定します。`works` に画像URLのある作品が設定されている場合、こちらを優先します。

```js
works: [
  {
    src: 'assets/photos/作品写真のファイル名.jpg',
    alt: '作品の見た目を説明する文章',
    title: '作品名',
    author: '作者名',
    year: '制作年',
    caption: '補足情報',
    comment: '制作に込めた思い',
    orientation: 'tall' // tall（縦）、wide（横）、square（正方形）
  }
]
```

作品を選ぶと写真と紹介を拡大表示します。閉じるボタン・Escapeキー・画面の外側から閉じられ、操作した作品にフォーカスが戻ります。掲載許可のある写真と作者情報を設定してください。

## アイコン

Bootstrap Icons v1.13.1 の公式素材 arrow-right、arrow-up-right、brush を使用。brushはブラウザーのサイトアイコンです。旧メニュー用のlistも同梱しています。MITライセンスの全文を `assets/icons/LICENSE.txt` に同梱し、`credits.html` から参照できます。生成アイコンは使用していません。

## 筆文字の字体

部名・大見出しには、書家の文字をもとにした「佑字 肅（Yuji Syuku）」を使用しています。本文・メニュー・小さなラベルはゴシックのままです。フォントはサイト内で配信し、外部フォントサービスへ接続しません。

`assets/fonts/YujiSyuku-subset.woff2` は現在のページの文字を含む軽量版です。見出しに新しい文字を追加する場合は、公式の原本から軽量版を作り直してください。含まれない文字には代替フォントが使われます。出典とライセンスは `assets/fonts/SOURCE.md` と `OFL.txt` に記録しています。

## ページと上部タブ

上部の5項目はそれぞれ独立したページに移動します。現在のページは白地と青い下線で表示し、`aria-current="page"` を設定しています。トップへは左上の部名、各ページのパンくずから戻れます。スマートフォンでも5項目を常に上部に表示し、横スクロールで選べます。現在の項目は最初に見える位置へ調整します。

全ページに共通フッター、ページ説明、共有用のタイトル・説明、サイトアイコンがあります。公開URL・SNS共有画像は未設定です。公開先が決まったら `og:url`、`og:image`、canonical、サイトマップを実際のURLで追加できます。フォント・アイコンはサイト内で配信し、外部サービスへの常時接続はありません。

ホノルルフェスティバルの概要は、[公式サイト](https://www.honolulufestival.com/ja/festival/)を参照しています。イベントの開催予定と、書道部の参加・出演確定は分けて確認してください。
